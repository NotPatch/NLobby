Everything Your Lobby Needs

Every feature is configurable — enable, disable, or fine-tune from a single config.yml.

🧲

Spawn Management

Set a custom spawn point with /nlobby setspawn. Auto-teleport players on join and on death, preventing them from ever getting lost.

🦘

Double Jump

Let players leap through the air with configurable velocity multiplier, particle effects (CLOUD and more), and launch sounds.

🚀

Jet Boost

A hotbar firework rocket that launches players forward on left-click or upward on right-click, with a configurable millisecond cooldown.

👁️

Player Visibility

One-click toggle to hide or show all other players — perfect for players who want a distraction-free lobby experience.

🧭

Navigator GUI

A compass-triggered server selector inventory with fully configurable server entries, icons, lore, and slot positions.

🔢

Queue System

An orderly BungeeCord/Velocity queue that sends players to target servers one by one with a live action-bar position display.

⚡

Direct Connect

Instantly send one player or all players on the server (* wildcard) to any connected server with a single command.

💬

Chat Formatting

Custom chat format with %level% and %player% placeholders, styled with Minecraft color codes.

🪙

Coins System

Per-player coin balances persisted in SQLite or MySQL via HikariCP. Commands to give, take, set, and check balances.

🏆

Level System

Track player levels with admin set/check commands and in-game level-up notifications to celebrate progression.

🎆

Join Effects

Welcome players with fireworks and a customizable title/subtitle screen that shows their name and coin balance.

🛡️

Lobby Protection

Block damage, hunger, building, and item pickup. Lock weather and freeze time at any configurable tick value.

🕳️

Void Teleport

Automatically teleports players back to spawn when they fall below a configurable Y-coordinate — no more void deaths.

🌐

Multi-Language Support

Ships with English (en_US) and Turkish (tr_TR). Add any language by dropping a new locale file — zero code changes needed.

🗄️

SQLite & MySQL

Choose between embedded SQLite for easy single-server setups or MySQL for shared databases across a network, pooled via HikariCP.

How It Works

NLobby hooks into PaperMC's event system and the BungeeCord/Velocity plugin-messaging channel to coordinate everything seamlessly.

1

Player Joins

On join, NLobby loads the player's data (coins & level) from the database, teleports them to spawn, fires join effects, and equips the configured hotbar items.

2

Hotbar Interaction

Compass opens the Navigator GUI. Ender Eye toggles visibility. Firework Rocket triggers the Jet Boost. All items and slots are fully configurable.

3

Navigator Selection

Clicking a server icon in the Navigator GUI puts the player in the configured server's queue. Queue positions are broadcast via the action bar in real time.

4

Queue Processing

Every tick-interval seconds, NLobby sends the next player in each queue to their target server via the BungeeCord/Velocity plugin-messaging channel.

5

Protection Layer

Event listeners silently cancel damage, hunger, block breaking/placing, and item pickup events, keeping the lobby environment clean and controlled.

6

Data Persistence

Coins and levels are saved to the database asynchronously on change and flushed on quit, ensuring no data loss even under heavy load.

Configuration Preview

All behavior is controlled from a single config.yml — no restarts required after /nlobby reload.

# Choose SQLITE for local storage or MYSQL for a shared network database
database:
  type: SQLITE        # SQLITE or MYSQL
  host: localhost
  port: 3306
  name: nlobby
  username: root
  password: ""
  pool-size: 5         # HikariCP connection pool size
double-jump:
  enabled: true
  permission-required: false   # Set true to restrict to nlobby.doublejump
  permission: nlobby.doublejump
  velocity-multiplier: 1.5       # Jump height/distance multiplier
  particle: CLOUD                 # Any Bukkit Particle enum value
  sound: ENTITY_FIREWORK_ROCKET_LAUNCH
navigator:
  gui-title: "&8Navigator"
  gui-size: 27               # Must be a multiple of 9
  servers:
    - name: "&aSurvival"
      material: GRASS_BLOCK
      lore:
        - "&7Click to connect"
      slot: 11
      server: survival       # BungeeCord/Velocity server name
    - name: "&cSkyWars"
      material: FEATHER
      lore:
        - "&7Click to connect"
      slot: 13
      server: skywars
queue:
  tick-interval: 3                   # Seconds between each queue dispatch
  show-position-actionbar: true
  actionbar-text: "&6Queue: &f%position% &7/ &f%total% &8| &7Server: &f%server%"
  servers:             # Whitelisted servers that can be queued
    - survival
    - skywars
    - creative
    - pvp
join-effects:
  firework: true
  title: true
  title-text: "&6Welcome back, &f%player%&6!"
  subtitle-text: "&7You have %coins% coins"
  title-fade-in: 10
  title-stay: 40
  title-fade-out: 10

Commands & Permissions

All administrative commands require the nlobby.admin permission. Player-facing commands are available by default.

Command Description Permission
/nlobby reload Reload the plugin configuration live nlobby.admin
/nlobby setspawn Set the spawn to your current location nlobby.admin
/nlobby version Show the current plugin version —
/spawn Teleport yourself to the spawn point —
/coins give <player> <amount> Give coins to a player nlobby.coins.give
/coins take <player> <amount> Remove coins from a player nlobby.coins.take
/coins set <player> <amount> Set a player's exact coin balance nlobby.coins.set
/coins check [player] Check your or another player's balance —
/level set <player> <level> Set a player's level nlobby.admin
/level check [player] Check your or another player's level —
/queue <player|*> <server> Add a player (or * for all) to a server queue nlobby.admin
/direct <player|*> <server> Instantly send a player (or all) to a server nlobby.admin

Permission Nodes

Permission Description
nlobby.admin Full administrative access (reload, setspawn, queue, direct, level set)
nlobby.doublejump Use double jump (only enforced when permission-required: true)
nlobby.jet Use jet boost (only enforced when permission-required: true)
nlobby.coins.give Give coins to players via /coins give
nlobby.coins.take Remove coins from players via /coins take
nlobby.coins.set Set a player's coin balance via /coins set
